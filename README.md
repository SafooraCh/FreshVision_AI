# 🥦 FreshVision

AI-powered **food type recognition** and **freshness detection** from images, powered by a multi-task CNN and served through an interactive Streamlit dashboard.

FreshVision looks at a photo of produce and answers two questions at once:
1. **What food is this?** (e.g. apple, banana, tomato, potato...)
2. **Is it fresh or rotten?**

---

## ✨ Features

- **Multi-task CNN** — a shared convolutional backbone with two output heads: a softmax classifier for food type and a sigmoid classifier for freshness.
- **Class-imbalance handling** via computed class weights for both tasks.
- **Data augmentation** (flip, rotation, zoom, contrast) applied only to the training split.
- **Full evaluation suite** — per-task accuracy, precision, recall, F1, and confusion matrices.
- **Reusable artifact bundle** (`.pkl`) — label mappings, class weights, training history, and metrics saved alongside the model so nothing needs to be recomputed later.
- **Polished Streamlit app** (`app.py`) with:
  - Live single-image prediction with confidence gauges
  - Batch upload mode with CSV export
  - A model insights dashboard (training curves, confusion matrices, metrics)

## 🧠 Model architecture

```
Input (128 × 128 × 3)
  → [Conv2D → BatchNorm → MaxPool] × 4   (32 → 64 → 128 → 256 filters)
  → GlobalAveragePooling2D
  → Dense(256) → Dropout(0.4)            (shared trunk)
  ├── Dense(128) → Dropout(0.3) → Dense(num_food_classes, softmax)   → food_type_output
  └── Dense(64)  → Dropout(0.3) → Dense(1, sigmoid)                  → freshness_output
```

Trained with `Adam` (lr `1e-3`), `sparse_categorical_crossentropy` for food type, `binary_crossentropy` for freshness, and callbacks for early stopping, LR reduction on plateau, and best-checkpoint saving.

## 🏋️ Training the model

The training pipeline (`freshvision_cnn_pipeline.py`) is written for a **Kaggle notebook environment** and expects a Freshness-style dataset (folders named with food type + fresh/rotten) mounted under `/kaggle/input`.

1. Open a Kaggle notebook and add the dataset via **+ Add Data**.
2. Paste in / run `freshvision_cnn_pipeline.py` cell by cell (or as a script).
3. The pipeline will:
   - Auto-discover the dataset folder and parse `(food_type, freshness)` labels from file paths
   - Split into stratified train / val / test sets (70 / 15 / 15)
   - Train the multi-task CNN with class weighting and augmentation
   - Evaluate on the test set and generate classification reports + confusion matrices
   - Save `freshvision_cnn_final.keras` and `freshvision_artifacts.pkl`

Download both output files from the notebook's **Output** tab when training finishes.

## 🖥️ Running the app

1. Place `freshvision_cnn_final.keras` and `freshvision_artifacts.pkl` in the same folder as `app.py`.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the app:
   ```bash
   streamlit run app.py
   ```
4. Open the URL Streamlit prints (usually `http://localhost:8501`).

### App tabs

| Tab | What it does |
|---|---|
| 🔍 Predict | Upload one image → food type + freshness with confidence gauges and a top-5 prediction chart |

## 📦 Artifact bundle contents (`freshvision_artifacts.pkl`)

| Key | Description |
|---|---|
| `img_size` | Input image dimensions used at train time |
| `food_types`, `food_type_to_idx`, `idx_to_food_type` | Food label vocabulary |
| `num_food_classes` | Number of food categories |
| `food_class_weight_dict`, `fresh_class_weight_dict` | Class weights used to mitigate imbalance |
| `history` | Full Keras training history (loss/accuracy per epoch) |
| `test_results` | `model.evaluate()` output on the held-out test set |
| `food_classification_report`, `freshness_classification_report` | Per-class precision/recall/F1 (as dicts) |
| `confusion_matrix_food`, `confusion_matrix_freshness` | Confusion matrices (NumPy arrays) |
| `summary_table` | Macro accuracy/precision/recall/F1 per task |
| `keras_model_path` | Filename of the saved `.keras` model |

Reload it like this:

```python
import pickle
import tensorflow as tf

with open("freshvision_artifacts.pkl", "rb") as f:
    bundle = pickle.load(f)

model = tf.keras.models.load_model(bundle["keras_model_path"])
```

## ⚠️ Notes & limitations

- This is a demo/prototype classifier — predictions should not be relied on for food safety decisions.
- Model performance depends heavily on the training dataset's coverage of food types, lighting conditions, and freshness stages.
- The app expects the `.keras` model and `.pkl` bundle to match (i.e., produced by the same training run) — mixing artifacts from different runs may cause label mismatches.
